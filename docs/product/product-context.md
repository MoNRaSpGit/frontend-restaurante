# Contexto funcional del producto

Fecha de actualizacion: 2026-05-16

## Lectura inicial del modulo

`restaurante` apunta a convertirse en una experiencia de producto para operacion gastronomica.

En una etapa madura podria cubrir:

- reservas
- mesas
- carta
- cocina
- delivery o retiro
- caja
- reportes basicos

## Regla para este inicio

Este frontend no declara aun el alcance final del producto.

En este corte solo busca:

- abrir una base de frontend propia del modulo
- dejar un lenguaje visual coherente
- facilitar validacion rapida en vivo
